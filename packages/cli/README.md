# PoB Headless CLI

This workspace package exposes the pob-web Path of Building runtime as a small headless Node.js API and JSON CLI.

It is intended to support downstream automation that needs deterministic PoB panel stats before making upgrade or trade-candidate recommendations.

## Scope

- Load a PoB share code from `pob.txt`.
- Read stable panel stats as JSON.
- Export the current in-memory build back to a PoB share code.
- Equip item text into a supported slot.
- Compare before/after stats and restore the original build.
- Verify a single trade candidate or batch-compare candidate item text files.

## Runtime

The API expects a packed PoB runtime under the pob-web workspace:

```text
packages/packer/build/poe1/<version>/root-zipfs
```

The bundle generated by this package copies that runtime into the npm package, so downstream repositories do not need a local pob-web checkout.

Set `POB_WEB_VERSION` to choose a runtime:

```bash
POB_WEB_VERSION=dev-aeccaca6 npm run test --workspace packages/cli
```

## CLI

```bash
node packages/cli/src/pob-headless-cli.mjs list-slots --pretty
node packages/cli/src/pob-headless-cli.mjs stats --pob /absolute/path/to/pob.txt --pretty
node packages/cli/src/pob-headless-cli.mjs export-code --pob /absolute/path/to/pob.txt --pretty
node packages/cli/src/pob-headless-cli.mjs compare-item --pob /absolute/path/to/pob.txt --slot "Weapon 2" --item /absolute/path/to/item.txt --pretty
node packages/cli/src/pob-headless-cli.mjs batch-compare --pob /absolute/path/to/pob.txt --slot "Weapon 2" --items /absolute/path/to/candidates --pretty
node packages/cli/src/pob-headless-cli.mjs verify-candidate --pob /absolute/path/to/pob.txt --slot "Weapon 2" --item /absolute/path/to/item.txt --pretty
```

`batch-compare` accepts item text files, directories containing `.txt` files, or simple glob patterns. It loads the PoB once, compares every candidate, restores after each item, and returns sorted JSON with a summary and per-item decision.

`verify-candidate` is a single-candidate convenience subcommand on the same `pob-headless` binary. It returns the compare result plus a coarse decision:

- `upgrade_candidate`
- `manual_review`
- `downgrade_skip`

## Tests

```bash
npm run test --workspace packages/cli
POB_WEB_VERSION=dev-aeccaca6 npm run test --workspace packages/cli
```

The test suite covers baseline stats, `getBuildCode()` round-trip, item compare/restore for both weapon slots, invalid slot errors, invalid item text errors, `batch-compare`, and `verify-candidate`.

## Bundle

Build a self-contained directory bundle:

```bash
POB_WEB_VERSION=dev-aeccaca6 npm run build:bundle --workspace packages/cli
```

This creates:

```text
packages/cli/dist/pob-headless-dev-aeccaca6/
```

The bundle includes the CLI, driver wasm files, packed PoB runtime, `package.json`, `LICENSE`, `NOTICE.md`, and the executable `bin/pob-headless` wrapper. It still requires Node.js 24+.

Pack the generated bundle:

```bash
cd packages/cli/dist/pob-headless-dev-aeccaca6
npm pack
```

The resulting package is named `@hydra1983/pob-headless-cli`, and the main binary is `pob-headless`.
